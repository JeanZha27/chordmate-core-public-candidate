# ChordMate Core

[English](./README.md) | 简体中文

## 产品介绍

ChordMate Core 是一个使用纯 TypeScript 编写的音乐理论与 MIDI 构建程序库。它负责把结构化的和弦名称、调性和级数进行，转换为可供其他软件继续使用的理论结果与 MIDI 数据。

它可以作为音乐学习工具、编曲辅助工具、可视化和弦应用或其他音乐软件的底层计算模块。例如，上层应用可以使用 Core：

- 读取和弦名称，并得到经过理论拼写的构成音；
- 生成大调与自然小调音阶，以及这些调性中的调内和弦；
- 按目标调移调级数和弦进行；
- 生成基础转位和有限的钢琴演奏排列；
- 计算供试听与排列参考使用的声部连接指标；
- 在内存中生成可以交给浏览器下载或其他程序处理的标准 MIDI 文件数据。

Core 本身不是完整的 ChordMate 产品，也不是网页、播放器或在线服务。它不负责用户界面、真实乐器音色、浏览器下载、用户账户、云端存储或数据分析。ChordMate Basic 等上层应用可以依赖 Core；Core 不依赖这些应用。

Core 的目标是提供一个范围清楚、结果可复现、便于测试和复用的基础引擎，而不是自动完成作品级和声分析，也不替代作曲教师、音乐理论教材或专业 DAW。

## Core 与 ChordMate Basic 的关系

可以把 Core 理解为“计算层”，把 Basic 理解为“用户可以看到和操作的演示应用”。

Core 负责：

- 解析输入；
- 计算音阶、和弦构成、理论拼写和转位；
- 生成演奏排列与声部连接参考数据；
- 构建 MIDI 二进制数据；
- 使用稳定错误类型拒绝未支持或无效的输入。

Basic 负责：

- 输入框、和弦卡片、钢琴键盘及播放控制；
- Web Audio 试听；
- MIDI 文件下载；
- 面向学习者的说明文字和错误呈现；
- 浏览器、移动端及无障碍交互。

本仓库公开的范围只有 Core。Basic、Studio 和吉他模块不包含在这个公开仓库中。

## 最小调用示例

npm 包尚未发布。将本仓库构建完成并以 `@chordmate/core` 的形式链接到支持 ESM 的打包项目后，下面的代码会把级数进行读取为确定性的理论数据。它不会播放音频、下载文件或控制 DAW。

```ts
import { parseChordInput } from '@chordmate/core'

const result = parseChordInput('C大调 I-vi-IV-V')

console.log(result.chords.map(({ name, notes }) => `${name}: ${notes.join(' · ')}`))
// [
//   'C: C · E · G',
//   'Am: A · C · E',
//   'F: F · A · C',
//   'G: G · B · D',
// ]
```

## 模块兼容性

构建输出面向支持 ESM 的打包工具。由于内部相对导入仍保留无扩展名写法，当前版本不承诺可以由原生 Node ESM 直接执行。

## MIDI 边界

Core 生成的是标准 MIDI 文件的二进制数据 `Uint8Array`，不是音频文件，也不包含真实钢琴或吉他音色。

MIDI 构建可以包含音符、速度、时值、轨道标题和由调用者提供的和弦 Marker。Core 不会根据作品自动推断拍号、调号、曲名或完整编曲信息，也不自动控制 Logic Pro 或其他 DAW。

不同 DAW 对音色、轨道和部分元数据的呈现方式可能不同。上层应用负责保存、下载、导入和播放这些数据。

## 理论与教学边界

- 理论音名与实际 MIDI 音高是相关但不同的信息；同一音高可能因理论语境采用不同拼写。
- 斜线和弦表示输入指定的最低音；该低音可能是和弦成员，也可能是非和弦低音。
- Core 支持的转位与演奏排列属于有限产品范围，不等于穷举所有可能声位。
- 声部连接结果是启发式参考指标，不是严格四部和声判定。
- `functional-chromatic`、`applied` 等字段是受支持输入的分类，不自动构成对完整作品的功能和声分析结论。
- 未支持的写法通常表示当前产品语法边界，不代表该写法在音乐理论上无效。
